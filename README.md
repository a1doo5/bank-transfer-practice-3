# Практическая работа №3

Консольное Java-приложение для перевода денег между двумя банковскими счетами.

## Возможности

- Проверка данных при создании счёта.
- Пополнение и списание средств.
- Проверка суммы и баланса при переводе.
- Обработка ошибок с помощью `try`, `catch`, `finally`, `throw` и `throws`.
- Собственное исключение `InsufficientFundsException`.

## Запуск

Открыть папку проекта в VS Code и запустить `Main.java` либо выполнить в терминале:

```bash
javac -encoding UTF-8 Main.java BankAccount.java TransferService.java InsufficientFundsException.java
java Main
```

Начальные балансы: Aida — 50000, Dana — 10000. После каждой попытки перевода программа выводит балансы обоих счетов.

## Проверка

Каждый ввод нужно проверять при отдельном запуске программы.

| Ввод | Ожидаемый результат | Баланс Aida | Баланс Dana |
| --- | --- | ---: | ---: |
| 5000 | Успешный перевод | 45000 | 15000 |
| 100000 | Недостаточно средств | 50000 | 10000 |
| -500 | Некорректная сумма | 50000 | 10000 |
| 0 | Некорректная сумма | 50000 | 10000 |
| abc | Ошибка ввода числа | 50000 | 10000 |
